twitch、kick + youtube 直播聊天，一個面板搞定 — 同時讀你所有的頻道，不用 alt-tab 就能在任一個裡回覆。同時在三個平台開播的實況主就是一個分頁。另外還有你自己的表情，任何頻道都能用：5,000 個免費表情位，不用訂閱，實況主那邊也不用設定。其他 heatsync 使用者看得到；其他人看到的是一般名稱。免費。

• 跨平台多聊天 — twitch、kick + youtube 直播聊天放在一個有分頁的面板裡：每個頻道一個分頁，或每位實況主一個分頁，三個聊天合在一起。有提及 + 悄悄話分頁、正在直播的追隨清單，還能匯入你在 twitch + kick 的追隨。可以調整大小、停靠到任一邊緣，或彈出成獨立視窗。閱讀不需要帳號。

• 你的表情，任何頻道 — 上傳或匯入任何表情（7tv、bttv、ffz，或你自己的）到 5,000 個免費表情位的庫存裡，在 twitch + kick 自帶聊天和面板裡的任何頻道都能用。用 tab 補全任何 7tv 表情並傳送，它會自動幫你加入。點一下就能複製整個頻道的表情。選擇器裡有 gif + emoji。

• 內建 7tv / bttv / ffz — 它們的表情、paints + badges 會自己顯示，包括頻道的、全域的和個人的。不需要別的擴充功能。

• 鍵盤優先 — 打字時表情會變成圖片，還有訊息紀錄、回覆，以及能把直播聊天縮小到某個詞或 @name 的搜尋框。每個聊天輸入框都可以選擇開啟 vim 按鍵：twitch、kick、youtube + 面板。

• 管理 + 使用者 — 懸停時出現的管理按鈕，由你自己挑選（刪除、timeouts、purge、ban、unban），twitch 的 automod 佇列，管理工具（shield mode、unban 請求、封鎖詞）和管理日誌。資料卡帶有追隨時間、badges、代名詞、私人備註和聊天紀錄。靜音或封鎖會連同這個人關聯的帳號一起生效。一鍵剪輯正在直播的 twitch 串流。

• 直播事件 + 過濾 — 開播、raids、hype trains、訂閱、兌換、預測、投票、youtube super chats + 會員，每一項都能單獨開關。過濾規則可依詞、使用者、badge 或類型標示或隱藏聊天。頻道點數在 twitch 上會自動領取。
