twitch、kick + youtube 直播聊天，一个面板搞定 — 同时读你所有的频道，不用 alt-tab 就能在任意一个里回复。同时在三个平台开播的主播就是一个标签页。另外还有你自己的表情，任何频道都能用：5,000 个免费表情位，不用订阅，主播那边也不用设置。其他 heatsync 用户能看到；其他人看到的是普通名字。免费。

• 跨平台多聊天 — twitch、kick + youtube 直播聊天放在一个带标签页的面板里：每个频道一个标签页，或每位主播一个标签页，三个聊天合在一起。有提及 + 私信标签页、正在直播的关注列表，还能导入你在 twitch + kick 的关注。可以调整大小、停靠到任意边缘，或弹出成单独窗口。阅读不需要账号。

• 你的表情，任何频道 — 上传或导入任意表情（7tv、bttv、ffz，或你自己的）到 5,000 个免费表情位的库里，在 twitch + kick 自带聊天和面板里的任何频道都能用。用 tab 补全任意 7tv 表情并发送，它会自动帮你添加。点一下就能复制整个频道的表情。选择器里有 gif + emoji。

• 内置 7tv / bttv / ffz — 它们的表情、paints + badges 会自己显示，包括频道的、全局的和个人的。不需要别的扩展。

• 键盘优先 — 打字时表情会变成图片，还有消息历史、回复，以及能把直播聊天缩小到某个词或 @name 的搜索框。每个聊天输入框都可以选择开启 vim 按键：twitch、kick、youtube + 面板。

• 管理 + 用户 — 悬停时出现的管理按钮，由你自己挑选（删除、timeouts、purge、ban、unban），twitch 的 automod 队列，管理工具（shield mode、unban 请求、屏蔽词）和管理日志。资料卡带有关注时长、badges、代词、私人备注和聊天记录。静音或拉黑会连同这个人关联的账号一起生效。一键剪辑正在直播的 twitch 流。

• 直播事件 + 过滤 — 开播、raids、hype trains、订阅、兑换、预测、投票、youtube super chats + 会员，每一项都能单独开关。过滤规则可按词、用户、badge 或类型高亮或隐藏聊天。频道积分在 twitch 上会自动领取。
