twitch・kick・youtube のライブチャットをひとつのパネルに — すべてのチャンネルを一度に読んで、alt-tab なしでどのチャンネルにも返信できます。3つすべてで配信中のストリーマーはひとつのタブにまとまります。さらに、どのチャンネルでも使える自分のエモート: 無料の5,000枠、サブ不要、ストリーマー側の設定も不要。ほかの heatsync ユーザーには見えて、それ以外の人には通常の名前で表示されます。無料。

• プラットフォーム横断マルチチャット — twitch・kick・youtube のライブチャットをタブ付きのひとつのパネルに: チャンネルごとのタブ、またはストリーマーごとに3つのチャットをまとめたタブ。メンション + ささやきのタブ、配信中のフォロー一覧、twitch + kick のフォローのインポート。サイズ変更、好きな端へのドッキング、別ウィンドウへの切り離しもできます。読むだけならアカウントは不要です。

• 自分のエモート、どのチャンネルでも — あらゆるエモート (7tv、bttv、ffz、または自作) をアップロードまたはインポートして、twitch + kick 本来のチャットとパネルのどのチャンネルでも使える、無料の5,000枠インベントリへ。7tv のエモートは tab で補完して送るだけ — 自動で追加されます。ワンクリックでチャンネルのエモートをまるごとコピー。ピッカーには gif + 絵文字。

• 7tv / bttv / ffz 内蔵 — それぞれのエモート、paints + badges が自動で表示されます。チャンネル用、グローバル、個人用のすべてに対応。ほかの拡張機能は不要です。

• キーボード優先 — 入力中にエモートが画像に変わり、メッセージ履歴、返信、ライブチャットを単語や @name で絞り込む検索ボックスも。すべてのチャット入力欄でオプトインの vim キーが使えます: twitch、kick、youtube + パネル。

• モデレーション + ユーザー — 好きなものを選べるホバー式のモッドボタン (削除、timeouts、purge、ban、unban)、twitch の automod キュー、モッドツール (shield mode、unban リクエスト、ブロックワード)、モッドログ。フォロー期間、badges、代名詞、非公開メモ、チャット履歴つきのプロフィールカード。ミュートやブロックは、その人のリンク済みアカウントにも及びます。配信中の twitch ストリームからワンクリックでクリップ。
