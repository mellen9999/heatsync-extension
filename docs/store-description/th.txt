แชทสดของ twitch, kick + youtube ในแผงเดียว — อ่านทุกช่องของคุณพร้อมกันและตอบในช่องไหนก็ได้โดยไม่ต้อง alt-tab สตรีมเมอร์ที่ไลฟ์ทั้งสามแพลตฟอร์มคือหนึ่งแท็บ พร้อมอิโมทของคุณเองในทุกช่อง: 5,000 ช่องฟรี ไม่ต้องซับ สตรีมเมอร์ไม่ต้องตั้งค่าอะไร ผู้ใช้ heatsync คนอื่นเห็นอิโมทเหล่านั้น คนอื่นนอกนั้นเห็นเป็นชื่อธรรมดา ฟรี

• มัลติแชทข้ามแพลตฟอร์ม — แชทสดของ twitch, kick + youtube ในแผงแบบแท็บเดียว: หนึ่งแท็บต่อช่อง หรือหนึ่งแท็บต่อสตรีมเมอร์ที่รวมแชททั้งสามไว้ด้วยกัน มีแท็บการกล่าวถึง + กระซิบ รายการผู้ที่ติดตามและกำลังไลฟ์ และการนำเข้าผู้ที่คุณติดตามจาก twitch + kick ปรับขนาด ยึดไว้ที่ขอบไหนก็ได้ หรือแยกออกเป็นหน้าต่างต่างหาก ไม่ต้องมีบัญชีก็อ่านได้

• อิโมทของคุณ ทุกช่อง — อัปโหลดหรือนำเข้าอิโมทใดก็ได้ (7tv, bttv, ffz หรือของคุณเอง) ไปไว้ในคลังฟรี 5,000 ช่องที่ใช้ได้ในแชทของ twitch + kick เองและในแผง ในทุกช่อง กด tab เติมอิโมท 7tv ใดก็ได้แล้วส่งเลย — ระบบเพิ่มให้คุณ คลิกเดียวคัดลอกอิโมททั้งหมดของช่อง gif + อีโมจิในตัวเลือก

• มี 7tv / bttv / ffz ในตัว — อิโมท, paints + badges ของพวกเขาแสดงเองทั้งของช่อง ของส่วนกลาง และของส่วนตัว ไม่ต้องใช้ส่วนขยายอื่น

• คีย์บอร์ดมาก่อน — อิโมทกลายเป็นรูปภาพขณะที่คุณพิมพ์ ประวัติข้อความ การตอบกลับ และช่องค้นหาที่ย่อแชทสดให้เหลือคำหรือ @name ที่ต้องการ มีปุ่ม vim ให้เปิดใช้เองได้ในทุกช่องแชท: twitch, kick, youtube + แผง

• การดูแล + ผู้คน — ปุ่มม็อดที่โผล่ตอนวางเมาส์ซึ่งคุณเลือกเอง (ลบ, timeouts, purge, ban, unban) คิว automod ของ twitch เครื่องมือม็อด (shield mode, คำขอ unban, คำที่ถูกบล็อก) และบันทึกม็อด การ์ดโปรไฟล์ที่มีระยะเวลาติดตาม, badges, สรรพนาม, โน้ตส่วนตัว และประวัติแชท การปิดเสียงหรือบล็อกจะตามไปถึงบัญชีที่เชื่อมโยงของคนคนนั้น คลิปจากสตรีม twitch ที่กำลังไลฟ์ด้วยคลิกเดียว

• อีเวนต์สตรีม + ตัวกรอง — เริ่มไลฟ์, raids, hype trains, subs, การแลกรางวัล, การทำนาย, โพล, youtube super chats + สมาชิก เปิดหรือปิดได้ทีละอย่าง กฎตัวกรองไฮไลต์หรือซ่อนแชทตามคำ ผู้ใช้ badge หรือประเภท แต้มช่องจะถูกรับเองบน twitch
